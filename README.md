# Yellow Platformer

A 2D platformer built in Godot 4.5. You race a green rival for stars across themed levels: grassland, desert, underwater, snowy mountain, a vertical summit climb, and a switch puzzle.

## Running the game

1. Install [Godot 4.5](https://godotengine.org/download) (standard build; the project uses the GL Compatibility renderer).
2. In the Godot project manager, choose **Import** and select `project.godot`.
3. Press **F5** to play from the start screen, or open any level in `scenes/` and press **F6** to run just that scene.

## Controls

| Action | Keys |
| --- | --- |
| Move | ← → |
| Jump | Space, Enter, or ↑ (hold for a higher jump) |
| Climb ladder | ↑ ↓ while touching a ladder; Space or Enter jumps off |
| Shoot fireball | F or X |
| Pause | Esc |

**Debug builds only:** F1–F5 jump straight to Level01–Level05 from anywhere, including the start screen. These keys don't exist in an exported release build.

## Levels

| Level | Theme | What's in it | Rival |
| --- | --- | --- | --- |
| Level01 | Grassland | Key and locked door, slimes, bees, a ladder | Yes |
| Level02 | Desert | Springs, spikes, fire slimes, bees, checkpoints | Yes |
| Level03 | Underwater | Swimming movement, worms, fish | No |
| Level04 | Snowy mountain | Ice tiles, snails (stomp to shell them, kick the shell), a switch that reveals a hidden platform, a ladder tower | Yes |
| Level05 | Summit climb | A vertical climb with a spring, spikes, an ice room, a moving platform, and crumbling platforms | No |
| Level06 | Switch puzzle | Press the green switch to reel a chain and box out of your path; springs, water pits | No |

Each level's goal flag leads to the next, from Level01 through Level05.

> **Note:** Level06 isn't connected yet. Level05's goal doesn't lead to it, and it has no debug key. To play it, open `scenes/Level06.tscn` in the editor and press F6.

### The rival

In levels with a rival, a green character uses A* pathfinding over the level's tiles, ladders, and springs to race you to the stars. The HUD shows both star counts. It only knows walking, jumping, dropping, climbing, and springs, so levels built around moving or crumbling platforms don't have one.

## Project layout

```
scenes/     Levels (Level01–Level06), the start screen, and reusable pieces:
            player, rival, enemies, hazards, platforms, pickups, HUD
scripts/    GDScript for everything above, plus autoloads:
            GameState (level transitions), SFX, PauseMenu, DebugTools
tilesets/   One TileSet per theme (grass, sand, stone, snow)
assets/     Kenney New Platformer Pack sprites and sounds, plus one custom
            tile (assets/Sprites/Tiles/Custom/ice_block.png)
tools/      Python generators for Level04 and Level05
```

Slipperiness is stored on the tile itself: tiles with the `ice` custom data layer in `snow_tileset.tres` are slippery wherever they're placed.

## Level generators

`scenes/Level04.tscn` and `scenes/Level05.tscn` are generated by scripts, not built by hand. To change their layouts, edit the script and regenerate:

```bash
python tools/gen_level4.py
python tools/gen_level5.py
```

This needs Python 3 and nothing else. Each script overwrites its scene, so edits made to those two levels in the Godot editor will be lost the next time the script runs. The other levels are edited in the editor as usual.
